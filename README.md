# EBA Transparency Exercise: data explorer and preparation engine

Reads the original EBA files from data/year_YYYY/, builds the bank x quarter panel, documents every indicator and draws the charts.

- Run the app: `streamlit run app.py`
- Batch run: `python -m te_engine all --data data --out reports`
- Full instructions: INSTRUCTIUNI_RULARE.md; indicator dictionary: INDICATORI.md
